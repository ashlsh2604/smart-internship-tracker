# Phase 3: Searching Algorithms (Reserved)

This directory is reserved for searching algorithms integrated with internship records.

## Planned Algorithms:
1. **Linear Search**:
   - $O(N)$ sequential scan over unsorted internship collections.
   - Searches across company names, roles, and status tags.
2. **Binary Search**:
   - $O(\log N)$ logarithmic search over sorted internship arrays by `id` or normalized `companyName`.
   - Compares performance metrics against linear search for viva demonstration.
