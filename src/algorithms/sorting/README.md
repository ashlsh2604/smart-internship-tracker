# Phase 3: Sorting Algorithms (Reserved)

This directory is reserved for sorting algorithms operating on internship records.

## Planned Algorithms:
1. **Merge Sort**:
   - Stable divide-and-conquer algorithm with guaranteed $O(N \log N)$ time complexity.
   - Sorts records by application deadline (earliest to latest) or priority.
2. **Quick Sort**:
   - In-place partitioning algorithm with average $O(N \log N)$ performance.
   - Sorts records alphabetically by company name or application date.
3. **Insertion Sort**:
   - Demonstrates adaptive $O(N)$ best-case behavior on nearly sorted application lists.
