# Phase 2: Hierarchical Tree Structures (Reserved)

This directory is reserved for tree structures and traversals in Phase 2.

## Planned Implementations:
1. **Binary Search Tree (`BST`)**:
   - Structured organization of internship records indexed by company name or application date.
   - Insert, search, and delete operations ($O(\log N)$ average case).
2. **Tree Traversals**:
   - **Inorder Traversal (Left, Root, Right)**: Yields internship records in strictly sorted order.
   - **Preorder Traversal (Root, Left, Right)**: Used for serializing the tree structure.
   - **Postorder Traversal (Left, Right, Root)**: Used for bottom-up cleanup and subtree operations.
