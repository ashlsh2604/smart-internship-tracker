# Algorithms (Reserved for Phase 2)

This directory is strictly reserved for Phase 2 of the Smart Internship Deadline Tracker project.

## Planned Implementations for Phase 2:
1. **Searching Algorithms (`search.ts`)**:
   - Multi-field search over company name, role, and application status.
   - Binary search on sorted company indices.
   - Prefix searching (Trie or substring pattern matching).

2. **Sorting Algorithms (`sort.ts`)**:
   - Merge Sort: Stable sorting by submission deadlines and company names.
   - Quick Sort: In-place sorting of applications by urgency or priority score.

*Note: Per Phase 1 requirements, no fake or premature DSA functionality is implemented here during authentication.*
